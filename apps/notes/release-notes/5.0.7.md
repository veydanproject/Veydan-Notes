## New

- Interface: the first start is a short guide through the language and sync.

## Improved

- Sync: setting up sync or changing its passphrase no longer freezes the screen for a few seconds.
- Interface: a "Finish setting up" card reminds you of what was skipped at the first start.
- Sync: choosing another storage now moves this device to it: the app asks first, and nothing on the device is lost.
- Interface: on Android, the system backup and phone transfer no longer copy the app's data.
- Interface: erasing all data now asks you to confirm it, with your unlock secret when the app lock is on.
- Sync: a deleted note no longer comes back, and a note restored from the trash on another device stays restored.
- Sync: one damaged file in the vault no longer stops your other notes from syncing.
- Notes: importing a folder takes only files inside it, and exporting never writes over a file that is already there.

## Fixed

- Editor: text typed on the phone while a note was saving is no longer lost.
- Editor: switching notes quickly no longer puts the text of one note into another.
- Notes: an attachment that is still downloading is no longer removed as unused.
- Sync: a conflict you resolved stays resolved, even if syncing fails right after.
